# ChronoDeck

ChronoDeck adalah **web-based futuristic clock & music player** dengan visual 3D, audio visualizer, dan tema siang/malam otomatis berdasarkan waktu lokal pengguna.

Proyek ini dibuat menggunakan **HTML, CSS, JavaScript**, serta **Three.js** dan **Web Audio API**, tanpa backend.

---

## Fitur Utama

- **Jam digital real-time**
- **Tanggal otomatis (lokalisasi browser)**
- **Day / Night mode otomatis**
- **Music player lokal (upload audio sendiri)**
- **Audio visualizer real-time**
- **Auto-random next track**
- **3D floating object (Three.js)**
- **Responsive & mobile friendly**
- **100% client-side (privacy-friendly)**

## Cara Menggunakan

1. Buka website di browser modern (Chrome, Edge, Firefox)
2. Klik **Upload Music**
3. Pilih satu atau beberapa file audio (MP3, WAV, dll)
4. Gunakan tombol:
   - Play / Pause
   - Previous
   - Next
5. Nikmati visualizer & animasi 3D

> Semua file audio **hanya diproses secara lokal**, tidak di-upload ke server mana pun.

---

## Catatan Penting

- Browser akan meminta **user interaction** sebelum audio bisa diputar (aturan AudioContext).
- Visualizer aktif saat musik diputar.
- Mode malam aktif otomatis pukul **18:00 – 06:00**.
